# Portfolio — Райхан Қайранбекова
Статический сайт (HTML/CSS/JS), без сборки.
- Все данные — в `js/config.js` (GitHub username, телефон, контакты, учёба, ссылка сайта).
- Запуск: VS Code → расширение Live Server → «Go Live».
- Публикация: GitHub → репозиторий → Settings → Pages → Deploy from branch → main / (root).
