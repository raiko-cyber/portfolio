# Портфолио Райхан Кайранбековой

Сайт: https://raiko-cyber.github.io/portfolio/

## Что где менять (в VS Code)

| Что менять | Файл |
|---|---|
| Контакты, образование, факультет, группа, ссылка сайта | `js/config.js` |
| Все тексты на русском, английском и казахском (Обо мне, навыки, проекты) | `js/i18n.js` |
| Внешний вид сайта и PDF-резюме (цвета, отступы, шаблон) | `css/style.css` |
| Порядок блоков на странице, раздел «Обо мне» | `index.html` |
| Логика сайта, сборка резюме | `js/main.js` |
| Фото (оно же в резюме) | `assets/photo.jpg` |

## Как опубликовать

В VS Code: Source Control (значок ветки) → написать сообщение → Commit → Sync Changes.
Через 1–2 минуты открыть сайт и нажать Ctrl+F5.

## Резюме (PDF)

Кнопка «Скачать CV» собирает резюме на том языке, который выбран на сайте (RU / EN / ҚАЗ).
В окне печати выберите «Сохранить как PDF».
