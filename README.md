## О проекте
Статический сайт без сборки и фреймворков. Сделан, чтобы за минуту понять, кто я, чем занимаюсь и как со мной связаться.

## Возможности
- Три языка: русский, английский, казахский
- Адаптивная вёрстка: удобно с телефона и с компьютера
- Скачивание CV в PDF
- QR-код со ссылкой на сайт

## Технологии
HTML, CSS, JavaScript, GitHub Pages

## Запуск локально
Открой папку в VS Code, установи расширение Live Server и нажми «Go Live».
Все личные данные (контакты, учёба, ссылка на сайт) лежат в `js/config.js`.
