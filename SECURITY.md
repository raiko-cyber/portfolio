# Security notes
- Сайт статический: нет сервера, форм, паролей и токенов. Никогда не добавляйте токены/ключи в файлы репозитория.
- Все данные из GitHub API выводятся через textContent, ссылки проверяются (только https://github.com/…).
- Content-Security-Policy задана в index.html. Если подключаете новый сторонний скрипт/шрифт/API — добавьте его домен в CSP.
- Во время разработки Live Server вставляет свой скрипт: CSP его блокирует, поэтому авто-обновление страницы может не работать — обновляйте F5.
- Включите двухфакторную защиту (2FA) на GitHub.
